**Busca de Referências**

_Pré-condições:_ O usuário está com a tela de escrita aberta

Cenário Principal de Sucesso:

1. O aluno abre a aba lateral de busca por material bibliográfico
2. O sistema mostra uma página de busca integrada ao _Google Scholar_ e uma área com as fontes já cadastradas no projeto sendo escrito
3. O usuário busca publicações relevantes na página de busca
4. Ao encontrar uma publicação que o aluno gostaria de citar, ele a arrasta com o mouse para a área de fontes cadastradas
5. O sistema registra as informações da publicação e cadastrá-la como uma fonte do projeto
