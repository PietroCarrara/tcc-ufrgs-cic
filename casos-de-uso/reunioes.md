**Definição de Horários de Reuniões**

Cenário Principal de Sucesso:

1. O usuário escolhe um de seus projetos de pesquisa para adicionar/editar um horário semanal de reunião
2. O sistema exibe um formulário com os dados da atividade e horários já ocupados por atividades dos membros do grupo
3. O usuário preenche e envia as informações
4. Os outros membros do projeto (alunos e professores) recebem uma notificação com os dados da reunião

Exceções:

- 3a: Conflito de Horários
    1. Ao enviar as informações, o usuário recebe um aviso de quaisquer conflitos de tempo que envolvam os outros membros do projeto
    2. Se o usuário escolher ignorá-lo, ele retorna ao CPS no passo 4
    3. Caso contrário, retorna ao CPS no caso 3
